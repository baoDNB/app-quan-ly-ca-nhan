# Nhà — App quản lý cá nhân

App tổng hợp ba công cụ: Nhịp (thời gian), Mây Note (ghi chú) và Ví Nhỏ (chi tiêu).

Đây là bản đóng gói độc lập: mã nguồn của cả ba mô-đun nằm trong thư mục `apps` và có thể deploy như một website tĩnh.

## Cách chạy

Nhấp đúp vào `Chạy ứng dụng.bat`, hoặc chạy:

```powershell
npm start
```

Trình duyệt sẽ tự mở tại `http://127.0.0.1:4320`.

Giữ cửa sổ lệnh mở trong lúc sử dụng. Để dừng app, đóng cửa sổ đó hoặc nhấn `Ctrl+C`.

Mọi dữ liệu được lưu trong `localStorage` của trình duyệt và không gửi tới máy chủ.
